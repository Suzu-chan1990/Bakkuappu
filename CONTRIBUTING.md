# Contributing to Bakkuappu

Contributions are welcome.

## How to contribute
1. Fork the repository
2. Create a feature branch
3. Commit your changes
4. Submit a pull request

## Guidelines
- Follow WordPress coding standards where practical
- Write all code comments in English
- Never write unencrypted backup data to disk
- Keep the backup format backwards compatible (older backups must stay readable)
- Avoid unnecessary dependencies
- Write clear commit messages

## Reporting issues
Please include:
- Bakkuappu version
- WordPress version
- PHP version
- Database server and version (MariaDB or MySQL)
- Whether the job was started from the admin, WP-CLI or the schedule
- Steps to reproduce
- The job log (Log tab) or the WP-CLI output

Remove keys, passwords and paths you do not want to share before posting logs.
